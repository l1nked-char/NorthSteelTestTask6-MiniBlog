## Blog Platform API
Бэкенд для блог-платформы с системой модерации на основе FastAPI и PostgreSQL.

### Описание проекта
API для управления постами и комментариями с ролевой системой пользователей. Платформа позволяет авторам создавать и публиковать контент, а модераторам контролировать качество публикуемых материалов.

### Жизненный цикл
- Посты:

DRAFT → PENDING <-> PUBLISHED <-> DELETED

1. DRAFT: Черновик, виден только автору
2. PENDING: На проверке, виден автору и модераторам (модераторы в списке постов на проверку не видят своего и не могут его опубликовать)
3. PUBLISHED: Опубликован, виден всем
4. DELETED: Удален, виден только модераторам

- Комментарии:

PENDING <-> PUBLISHED <-> DELETED

1. PENDING: На проверке
2. PUBLISHED: Опубликован
3. DELETED: Удален

### Основной функционал
- Управление постами:

1. Создание и редактирование постов
2. Отправка на модерацию
3. Публикация (только для модераторов)
4. Архивация и удаление
5. Просмотр постов с учетом прав доступа


- Система комментариев:

1. Комментирование опубликованных постов
2. Приватные комментарии (видны только автору поста и модераторам)
3. Модерация комментариев
4. Редактирование и удаление своих комментариев

### Ролевая модель:

1. Обычные пользователи: создание постов, комментирование, управление своим контентом
2. Модераторы: все права пользователей + модерация контента

### Авторизация и безопасность

1. JWT-аутентификация
2. Проверка прав доступа к каждому эндпоинту
3. Защита от несанкционированного доступа к чужим данным

### Технический стек
- Backend:

1. FastAPI - высокопроизводительный веб-фреймворк
2. Python 3.11+ - язык программирования
3. Uvicorn - ASGI-сервер

- База данных:

1. PostgreSQL - реляционная база данных
2. Psycopg2 - драйвер для работы с PostgreSQL

- Валидация данных:

1. Pydantic - валидация и сериализация данных
2. JWT - токены аутентификации

- Тестирование:

1. Pytest - фреймворк для unit-тестов
2. Async тестирование - для асинхронных эндпоинтов
