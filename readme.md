## Blog Platform API
Бэкенд для блог-платформы с системой модерации на основе FastAPI и PostgreSQL.

### Описание проекта
API для управления постами и комментариями с ролевой системой пользователей. Платформа позволяет авторам создавать и публиковать контент, а модераторам контролировать качество публикуемых материалов.

### Жизненный цикл
- Посты:

DRAFT → PENDING <-> PUBLISHED <-> DELETED

DRAFT: Черновик, виден только автору

PENDING: На проверке, виден автору и модераторам (модераторы в списке постов на проверку не видят своего и не могут его опубликовать)

PUBLISHED: Опубликован, виден всем

DELETED: Удален, виден только модераторам

- Комментарии:

PENDING <-> PUBLISHED <-> DELETED

PENDING: На проверке

PUBLISHED: Опубликован

DELETED: Удален

### Основной функционал
- Управление постами:

Создание и редактирование постов

Отправка на модерацию

Публикация (только для модераторов)

Архивация и удаление

Просмотр постов с учетом прав доступа


- Система комментариев:

Комментирование опубликованных постов

Приватные комментарии (видны только автору поста и модераторам)

Модерация комментариев

Редактирование и удаление своих комментариев

### Ролевая модель:

Обычные пользователи: создание постов, комментирование, управление своим контентом

Модераторы: все права пользователей + модерация контента

### Авторизация и безопасность

JWT-аутентификация

Проверка прав доступа к каждому эндпоинту

Защита от несанкционированного доступа к чужим данным

### Технический стек
- Backend:

FastAPI - высокопроизводительный веб-фреймворк

Python 3.11+ - язык программирования

Uvicorn - ASGI-сервер

- База данных:

PostgreSQL - реляционная база данных

Psycopg2 - драйвер для работы с PostgreSQL

- Валидация данных:

Pydantic - валидация и сериализация данных

JWT - токены аутентификации

- Тестирование:

Pytest - фреймворк для unit-тестов

Async тестирование - для асинхронных эндпоинтов
